## 2026-11-08 - Accessible State Indicators
**Learning:** This application relies on conditional inline styling and custom classes to indicate UI state selection (like active/selected).
**Action:** When adding or modifying these visual states, ensure they are paired with appropriate ARIA attributes (e.g., `aria-current="true"`, `aria-pressed="true"`) for accessibility so that screen readers correctly interpret the currently active/pressed elements.
