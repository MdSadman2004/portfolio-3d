## 2025-02-23 - Screen Reader Accessibility for Custom Button Groups
**Learning:** When building custom toggle button groups (like the visualization modes or dataset size toggles) using generic `<button>` elements styled to look like tabs or segmented controls, screen readers do not automatically announce their grouping or active state. The `title` attribute is often insufficient for conveying the full meaning of short-hand buttons to assistive technologies.
**Action:** For adjacent interactive buttons that function as a cohesive control set, wrap them in a container with `role="group"` and an `aria-label`. For toggleable state buttons, explicitly declare `aria-pressed={true/false}` based on the component's state. For buttons with terse labels (like numbers) but rich tooltips (`title`), apply an `aria-label` that interpolates the tooltip text so screen readers read the full context.
